# **Lab 13 – Inventory Control System**

### **1. Thinking Process** ###

1. First, I thought about making a menu-based program to manage a list of inventory items.
2. I decided to use a Python list to store items because adding, removing, and viewing items is simple with list operations.
3. I used a `while` loop so the menu keeps running until the user exits the program.
4. I used different `if-elif-else` conditions for add, remove, view, sort, and exit choices.
5. I also used the `title()` method to make item names look neat and consistent.
